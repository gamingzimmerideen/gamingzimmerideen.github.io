Deko für den Schreibtisch: 5 Ideen, damit dein Setup persönlicher wird

Dein Schreibtisch wirkt kahl? Eine kleine Pflanze neben dem Monitor, eine Lieblingsfigur als Blickfang, eine Duftkerze oder ein Diffuser, ein Foto im schmalen Rahmen und eine kleine LED-Lampe machen dein Setup persönlich. Weniger ist dabei mehr.

Auf einen Blick

  1. Kleine Pflanze neben den Monitor
  2. Lieblingsfigur als Blickfang
  3. Duftkerze oder Diffuser
  4. Foto in schmalem Rahmen
  5. Kleine LED-Lampe
Tipp: Halte dich an maximal drei Deko-Stücke auf dem Tisch – sonst wirkt es schnell unordentlich.
